# AURA — ثيم مجوهرات لمنصة سلة

كل قطعة في AURA محاطة بهالة من الضوء: اسم المتجر في الواجهة يحتضن القطعة بين حروفه، وحلقات ضوء رفيعة تنتشر حولها، والضوء يتبع مؤشر الزائر.

الثيم مبني على [Theme Raed](https://github.com/SallaApp/theme-raed) الرسمي من سلة (رخصة MIT)، فكل صفحات المتجر (المنتج، التصنيفات، السلة، حساب العميل) تعمل كما هي، وAURA يضيف الهوية والأقسام الخاصة بالمجوهرات.

## ما يعدّله التاجر من لوحة التحكم

إعدادات الثيم (قسم «هوية AURA»):

- **لون الهالة**: حجر القمر، شمبانيا، وردي، أوبال. يغيّر لون الضوء حول القطع والحلقات والروابط.
- **شكل صور المنتجات**: قوس، حواف ناعمة، مربّع. يُطبَّق على بطاقات المنتجات في المتجر كله.
- **اسم المتجر كنص بدل الشعار** + النص نفسه (افتراضياً AURA).

أقسام الصفحة الرئيسية (تُضاف وتُرتّب وتتكرر من محرر الصفحة):

| القسم | المحتوى القابل للتعديل |
|---|---|
| AURA: الواجهة المضيئة | صورة القطعة، صورة مفرّغة أو لا، العنوان، النص، الزر ورابطه، خلفية ليلية |
| AURA: تسوّق حسب القطعة | العنوان، النص، شكل الصور (دائرة/قوس/مربّع)، من ٢ إلى ٨ أقسام بصورة واسم ورابط |
| AURA: قطع مختارة | العنوان، النص، اختيار المنتجات (أو أحدث المنتجات تلقائياً)، رابط عرض الكل |
| AURA: قصة / حملة | صورة طولية، العنوان، النص، الزر، جهة الصورة، خلفية ليلية |
| AURA: وعود الشراء | العنوان، من ١ إلى ٤ وعود بأيقونة وعنوان ووصف |

كل أقسام ثيم رائد الأصلية ما زالت متاحة أيضاً، والخطوط وألوان سلة الأساسية تعمل كالمعتاد.

## الملفات التي أضافها AURA أو عدّلها

- `twilight.json`: الاسم، إعدادات الهوية، الأقسام الخمسة
- `src/views/components/home/aura-*.twig`: الأقسام الخمسة
- `src/assets/styles/06-aura/aura.scss`: طبقة التصميم (مستوردة في آخر `app.scss`)
- `src/assets/js/partials/aura-hero.js`: الضوء الذي يتبع المؤشر (مستورد في `home.js`)
- `src/views/layouts/master.twig`: الخطوط وربط الإعدادات بالألوان
- `src/views/components/header/header.twig`: الشعار النصي
- `src/locales/ar.json` و`en.json`: نص «عرض الكل»
- `public/`: الملفات المبنية الجاهزة

## الرفع على سلة

```bash
npm install -g @salla.sa/cli
salla login
```

1. ارفع هذا الفولدر كريبو جديد على GitHub.
2. `salla theme create` ← اختر استيراد ثيم موجود من GitHub ← اختر الريبو.
3. `pnpm install` ثم `salla theme preview` للمعاينة على متجر تجريبي.
4. من المحرر: أضف أقسام AURA وارفع الصور.
5. من بوابة الشركاء: بيانات الثيم، الصور، السعر، ثم النشر والمراجعة.

بعد أي تعديل على الكود: `pnpm run production` ثم ارفع التغييرات إلى GitHub.

## نصائح للصور

- **الواجهة**: صورة مربعة لقطعة واحدة. أفضل نتيجة مع PNG مفرّغ الخلفية وتفعيل «الصورة مفرّغة».
- **تسوّق حسب القطعة**: صور مربعة بخلفية فاتحة سادة.
- **قصة / حملة**: صورة طولية (900×1100).
- **اللون الأساسي للمتجر** من إعدادات سلة: اختر `#221E2B` ليتناسق زر «إضافة للسلة» مع الهوية.
